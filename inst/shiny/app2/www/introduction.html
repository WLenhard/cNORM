cNORM — Parametric Continuous Norming

This application models norm scores such as percentiles, T scores, IQ scores or z scores for psychometric, biometric and other data, using parametric continuous norming. Rather than norming each age group separately, the full distribution of the raw score is modelled as a smooth function of age. This interpolates between age groups, stabilizes the estimates at the tails and reduces the sample size required for stable norms.

Distribution-free alternative: if you prefer a model that makes no assumption about the distribution family (regression with Taylor polynomials on grouped data), use the distribution-free modelling app.

Quick start

  1. Data Input – select a built-in example or upload your own file. Review the data in the preview table.
  2. Modeling – select the age, raw-score and (optionally) weight variable, choose the distribution family, set the polynomial degrees and the norm scale, and click Compute Model. Check the percentile plot and the model summary. The fitted model can be downloaded as an .rds file.
  3. Norm Tables – enter the ages for which you need tables, define the raw-score range, optionally add confidence intervals and click Generate Tables. The tables can be downloaded as a CSV file.

How parametric continuous norming works

At every age, the raw score is assumed to follow a probability distribution from a selected family (see below). The parameters of this distribution (e. g. location, scale, skewness) are not constant but are modelled as polynomial functions of age; the polynomial degree controls how flexibly each parameter may change with age. The coefficients are estimated by (optionally weighted) maximum likelihood from the whole sample at once, so that all observations inform the estimate at every age.

To obtain a norm score, the observed raw score is converted into its cumulative probability (percentile) under the distribution fitted for the person's age, and this percentile is transformed to the chosen norm scale. The procedure is continuous in age, so ages need not coincide with the age groups of the standardization sample.

Data requirements

  • Age variable – numeric explanatory variable, ideally recorded continuously (e. g. decimal years). A variable named age is preselected automatically.
  • Raw-score variable – numeric test score. Variables named fluency, raw or score are preselected automatically; otherwise please check the selection. The permissible scale depends on the family (see below).
  • Weight variable (optional) – case weights, e. g. post-stratification weights that correct for deviations of the sample from the population (see computeWeights() in the R package).
  • File formats – .csv (comma-separated, with header row), .xlsx/.xls (first sheet), .sav (SPSS) and .rda (the first object in the file is used). An uploaded file overrides the selected example, and loading new data resets the current model and tables.

Choosing the distribution family

FamilyTypical dataParameters (polynomial in age)
Sinh-Arcsinh (SHASH) Continuous, unbounded scores; response times, difference scores, biometric data (e. g. BMI, height, weight). μ (location), σ (scale), ε (skewness), δ (tail weight). Default degrees 3, 2, 2, 1. δ may alternatively be fixed to a constant (δ = 1 with ε = 0 corresponds to the normal distribution).
Beta-Binomial Accuracy and power tests with a fixed number of items n (scores 0 to n), e. g. vocabulary or comprehension tests. Particularly appropriate for Rasch (1PL) scaled tests. α and β (shape parameters). Default degrees 3 and 3. The norm table covers the entire range from 0 to n.
Conway-Maxwell-Poisson (CMP)
new in cNORM 3.7		 Speeded tests, rates and counts (non-negative integers), such as the number of items processed within a time limit; scores may have a ceiling. μ (location) and ν (dispersion). Default degrees 3 and 2. ν = 1 is the Poisson distribution, ν < 1 indicates over-dispersion and ν > 1 under-dispersion, as is typical for speeded tests with bounded scores.

Family-specific options

  • SHASH – δ can be fixed instead of being modelled as a polynomial, which is a useful simplification when the tails do not change noticeably with age.
  • Beta-Binomial – the number of items n is the maximum attainable score. If this maximum is not observed in your data, please fit the model on the R console and set the number of items explicitly (see ?cnorm.betabinomial).
  • CMP – the dispersion ν can be modelled as a polynomial (degree 0 yields one constant, estimated value) or fixed to a value (e. g. 1 for a Poisson model). If the test has a ceiling, activate right-truncation and enter the maximum attainable score, so that no probability mass is assigned to scores above it. Raw scores must be non-negative integers.

Selecting polynomial degrees

The degree of a parameter determines how it may vary with age: degree 0 is constant, 1 is linear, 2 is quadratic and so on. Higher degrees capture more complex developmental trajectories but increase the risk of overfitting. Recommended strategy:

  1. Start with the default degrees for the selected family.
  2. Inspect the percentile plot, which shows observed percentiles (points) against the model predictions (lines). Systematic deviations between points and lines suggest that degrees are too low; wavy lines indicate overfitting, so reduce the degrees.
  3. Compare competing specifications using the Summary tab (parameter estimates and fit information). Prefer the most parsimonious model that reproduces the empirical percentiles well.
  4. Do not interpret the norms outside the age range covered by your sample, and be cautious with extreme percentiles in age ranges with few observations.

Norm scales

Norm scores can be expressed as T scores (M = 50, SD = 10), IQ scores (M = 100, SD = 15) or z scores (M = 0, SD = 1). Percentile ranks are included in the norm tables.

Generating norm tables

  • Ages – enter one or more ages separated by commas or spaces (e. g. 7, 8, 9, 10); one table per age is created.
  • Raw-score range – start, end and step size are preset from your data. For CMP, scores are integers and percentiles are evaluated with a mid-p adjustment. For the Beta-Binomial family, the complete range 0 to n is generated and start/end can only be used to restrict the display.
  • Confidence intervals – optionally specify a confidence level and the reliability coefficient of the test; the intervals reflect measurement error of the test and are added to the norm scores.

Working on the R console

The app covers the core workflow. Additional options, such as automatic selection of polynomial degrees (autoselect.shash(), autoselect.betabinomial()) and further diagnostics, are available in the R package. A downloaded model (.rds) can be reloaded with readRDS() and used for further predictions.

library(cNORM)

model <- cnorm.cmp(age = speed$age, score = speed$fluency,
                   mu_degree = 3, nu_degree = 2, max_score = 75)
summary(model, age = speed$age, score = speed$fluency)
tables <- normTable.cmp(model, ages = c(8, 9, 10), start = 0, end = 75)

vignette("BetaBinomial", package = "cNORM")

Further information: Psychometrica and the package vignettes on CRAN. The package can also be launched locally with cNORM.GUI().

Privacy

When launched locally, all data stays on your computer. The online application is hosted on ISO 27001-certified IONOS servers located in the European Union (Frankfurt, Germany), in compliance with the General Data Protection Regulation (GDPR). cNORM does not store uploaded data; nothing you upload is retained.
